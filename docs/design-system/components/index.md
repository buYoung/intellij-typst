# 구성 요소 목록

현재 문서화 대상은 아이콘이다. 다른 UI 구성 요소는 이 요청의 범위에 포함하지 않는다.

| 구성 요소 | 범위 | 상태 |
| --- | --- | --- |
| [아이콘](icons.md) | 언어 틀·기능 기호 원형, 파일 식별, 테마·상태, 실제 소비자 | v3 상세 분석 반영, Typst 자산 제작 전 |

제품 로고·상점 이미지의 목록은 [시각 자산 체계](../visual-assets/asset-system.md)에 있다.

개별 구성 요소를 넘어서는 글자·간격은 [값과 연결](../tokens.md), 작업과 결과의 관계는 [공통 패턴](../patterns.md), 상태·색 대비는 [접근성](../accessibility.md)을 따른다.
