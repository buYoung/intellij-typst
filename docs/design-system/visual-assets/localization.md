# 이미지의 언어와 현지화

문서 설명은 한국어로 작성한다. 이미지 속 제품명은 `Typstninja`, 언어 이름은 `Typst`로 유지한다.

현재 [메시지 리소스](../../../src/main/resources/messages/MyBundle.properties)와 [동작 등록](../../../src/main/resources/META-INF/plugin.xml)에서 영문 UI를 확인했다. 기본 상점 이미지도 JSONinja의 공개 이미지와 같은 **영문 UI·영문 캡션** 조합으로 작성한다. 별도 한국어 이미지는 같은 장면의 번역 변형으로 관리하며 기본 이미지 안에 두 언어를 길게 병기하지 않는다.

번역 이미지를 만들 때는 기능과 상태가 같은 장면끼리 대응시킨다. 번역으로 문장이 길어지면 문구 영역을 조정하고, 제품 화면의 글자 크기를 줄여 해결하지 않는다. 한국어 설명을 붙이기 위해 실제 영문 IDE 메뉴나 오류 문구를 이미지 안에서 가짜 번역으로 교체하지 않는다.

지원하지 않는 현지화·지역별 변형을 완성된 기능처럼 표기하지 않는다. 상점 자체의 언어별 미디어 지원 여부는 [상점 문서](stores/jetbrains-marketplace.md)의 확인 범위를 따른다.

## 번역 변형의 고정 요소

| 유지 | 바꿀 수 있음 | 확인 |
| --- | --- | --- |
| 제품명·T·색 역할·실제 기능 장면 | 설명 문장과 줄바꿈 | 영어와 한국어가 같은 기능·조건을 말하는가 |
| 캡션의 계열·강조·정렬 | 번역에 필요한 문구 영역의 높이 | 제품 화면과 충돌하지 않는가 |
| 코드·파일명·메뉴 원문 | 설명에서 제공하는 한국어 뜻 | 실제 UI 문구를 가짜로 교체하지 않았는가 |

문장이 길어지면 기능명과 결과 설명을 분리하고, 불필요한 수식어를 줄인다. 기술 조건을 지우거나 글자를 무조건 작게 만들어 같은 칸에 넣지 않는다. RTL 등 실제로 요청하지 않은 언어 변형은 현재 지원 자산으로 표기하지 않는다.
