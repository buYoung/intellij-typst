# 납품과 확인 기록

현재 관리하는 납품물은 제작 기준 문서, 기존 원본의 분석용 비교판, 사용자가 선택한 로고 PNG와 선택 기록, Quiver 변환 SVG와 패키지용 테마 파일, 상점용 정보형 이미지 4장이다. 워드마크·실제 제품 캡처와 상점 게시 결과는 아직 없다.

## 방향의 근거와 성숙도

2026-09-26 사용자는 문서를 먼저 만들고, 로고는 기존 T·청록색을 유지하면서 T를 닌자화하되 너무 튀지 않고 JSONinja 로고와 일관되게 표현하도록 요청했다. 이 방향을 [시각 언어](visual-language.md)에 반영했다.

성숙도는 **로고 SVG 변환·패키지 적용 완료 / 실제 IDE 표시 미확인**이다. 사용자는 하찮고 멀뚱한 느낌으로 만든 10개 시안 중 02번 ‘모여 있는 눈’을 선택했다. 2026-09-27 Quiver MCP로 [선택한 원본](asset-system.md#확정한-로고-원본)을 벡터화하고 가까운 점눈·T 비율·두 곡선을 직접 비교했다. 패키지 SVG를 40·80px로 렌더링해 밝은·어두운 배경에서 확인했다. [비교판](logo/vectorization-review.png), [변환 기록](logo/vectorization.json)

## 제작 결과를 연결할 때

완성 자산은 [자산 목록](asset-system.md)에 실제 원본·내보내기 파일 경로를 연결한다. 파일명·상점·언어·테마·제품 버전의 대응이 드러나게 기록하며, 아직 존재하지 않는 경로를 완성 자산으로 표기하지 않는다.

현재 제품 버전은 [gradle.properties](../../../gradle.properties)의 `0.2.0`이다. 2026-09-27 사용자가 첫 Marketplace 제출 버전으로 확정했다. 참조 스타일의 v3는 Typstninja의 출시 버전 번호가 아니다. 촬영 당시 제품 버전·IDE 환경·예제·테마와 편집 원본을 함께 남겨, 기능이나 로고가 바뀌면 영향을 받는 이미지를 찾을 수 있게 한다.

로고 납품 파일과 패키지 경로는 [상점 규격](stores/jetbrains-marketplace.md)을 따른다. PNG 등 파생본의 개수·크기·알파 조건과 홍보 이미지의 저장 위치는 실제 제작 계약이 정해질 때 기록한다.

## 제작 단계에서 확정할 사항

| 사항 | 결정 시 필요한 근거 |
| --- | --- |
| 선택한 로고의 실제 IDE 표시 | SVG 변환·두 배경 비교·패키지 적용 완료. 실제 IDE DPI와 Marketplace 표시는 별도 확인 |
| 제품명에 사용한 실제 글꼴 이름·심볼 간격 | 정해진 산세리프 역할과 단독·결합 결과 |
| 최종 촬영 장면·파일 개수·캡션 줄바꿈 | 기본 네 가지 기능 역할, 영문 기본형, [기준 캔버스](stores/jetbrains-marketplace.md) 안에서 확정 |
| 영상 제작 여부 | 움직임이 정적 화면보다 기능 설명에 도움이 되는지 |

이 항목들은 현재 선택된 닌자화 T·청록색과 작은 아이콘의 v3 방향 안에서 후속 제작의 구체적인 결과를 정하기 위한 사항이다.

## 납품 시 남길 정보

원본·파생본·촬영 화면·캡션을 연결해 다음 내용을 기록한다. 정확한 경로는 파일을 만든 뒤 [자산 목록](asset-system.md)에 등록한다.

| 대상 | 남길 정보 |
| --- | --- |
| 심볼·파일 아이콘 | 원본 SVG, 용도, 테마, 캔버스, 색, 실제 연결 경로 |
| 제품명 조합 | 사용 글꼴·굵기, 편집 가능한 원본, 심볼과의 정렬·간격 |
| 상점 이미지 | 제품 버전·IDE·테마·배율, 예제, 원본 캡처, 캡션 텍스트·글꼴, 언어, 내보낸 크기 |
| 동작 설명 | 시작·행동·결과 상태, 편집·배속 여부, 정적인 대표 장면 |

같은 세트의 파생본은 하나의 편집 원본에서 만든다. 납품명에 쓰는 기능명·언어·테마가 실제 내용과 대응해야 한다. 분석용 비교판은 제품 납품 목록에서 제외한다.

제작 후에는 단순한 로고 단독 상황과 정보가 많은 제품 화면 상황을 비교하고, 밝은·어두운 배경 및 최종 표시 크기에서 확인한다. 문서 구조 검사만으로 시각 품질이나 상점 업로드 성공을 통과 처리하지 않는다.
