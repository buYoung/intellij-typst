# 색 대비와 식별성

브랜드 색을 유지하면서도 기능·설명·상태를 읽을 수 있어야 한다. 아래 수치는 불투명한 sRGB 색 쌍으로 계산한 대비이며, 얇은 선의 안티앨리어싱이나 실제 이미지 축소 결과까지 통과했다는 뜻은 아니다.

## 대비 기준과 예외

설명 문구는 일반 텍스트 4.5:1, 큰 텍스트 3:1을 판정 기준으로 사용한다. 큰 텍스트는 일반 18pt 이상 또는 굵은 14pt 이상을 기준으로 하며, 이미지 편집 원본이 아닌 최종 표시 크기로 판단한다. 로고·브랜드명에는 같은 텍스트 기준의 예외가 있지만, 로고 예외를 기능 설명이나 버튼 문구에 확대하지 않는다. [W3C 텍스트 대비 해설](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

동작이나 상태를 이해하는 데 필요한 그래픽은 인접 배경과 3:1을 기준으로 확인한다. 비활성 등 공식 예외와 실제 의미를 구분하며, 플랫폼이 제공하는 상태 표현을 임의의 브랜드 색으로 덮어쓰지 않는다. [W3C 비텍스트 대비 해설](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

## 현재 색의 계산 결과

`#1E1F22`는 이번 어두운 배경 비교에 사용한 검사색이며 모든 IDE 테마의 배경값으로 고정하는 토큰이 아니다. 표는 소수 둘째 자리까지 표시했지만 판정은 반올림 전 값으로 했다.

| 전경 / 배경 | 대비 | 사용 판단 |
| --- | --- | --- |
| `#6C707E` / `#FFFFFF` | 4.93:1 | 밝은 배경에서 v3 회색을 구분할 수 있는 색 조합 |
| `#CED0D6` / `#1E1F22` | 10.69:1 | 검사한 어두운 배경에서 v3 회색을 구분할 수 있는 조합 |
| `#239DAD` / `#FFFFFF` | 3.23:1 | 일반 본문에는 부족. 큰 글자·그래픽도 실제 형태를 따로 확인 |
| `#39B8C6` / `#FFFFFF` | 2.37:1 | 작은 기능 기호·설명 문구의 전경으로 사용하지 않음 |
| `#239DAD` / `#1E1F22` | 5.10:1 | 검사색 위 일반 글자의 수치 기준 충족 |
| `#39B8C6` / `#1E1F22` | 6.94:1 | 어두운 배경용 브랜드 강조에 적합한 수치 |
| `#FFFFFF` / `#000000` | 21:1 | 검은 캡션 띠와 흰 문구의 기본 조합 |

흰 T를 청록색 면 위에 놓아도 대비값은 같은 두 색의 조합이다. 현재 로고의 흰 T를 이유로 흰 작은 본문을 청록색 배경 위에 일괄 사용하는 규칙을 만들지 않는다. 색을 새로 바꾸기 전에 역할·배경·배치를 조정한다.

## 색 이외의 구별 수단

- 파일 종류·기능은 기호나 이름으로도 구분한다. 청록색과 회색만 바꿔 다른 기능을 만들지 않는다.
- 아이콘은 실제 동작 이름·툴팁과 연결한다. 선택·포커스·비활성은 IDE가 전달하는 상태와 함께 확인한다.
- 오류 화면은 실제 진단 문구와 위치를 남긴다. 색의 차이만 확대해서 오류를 설명하지 않는다.
- 작은 선은 원본 색의 대비가 충분해도 축소 과정에서 흐려질 수 있다. 실제 크기와 배율을 함께 확인한다.

상점 이미지와 영상의 세부 확인 항목은 [시각 자산의 가독성](visual-assets/accessibility.md)에 있다. 이 문서는 제품 전체의 WCAG 적합성 인증을 주장하지 않는다.
